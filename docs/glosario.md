# Glosario (peras y manzanas)

| Término | En simple |
|---|---|
| **SKU** | El código de un producto concreto (una referencia). |
| **SC / Sugerido de Compras** | La lista de “cuánto pedir” de cada SKU. |
| **ABCI** | Ranking de importancia por ventas (Pareto). S = súper crítico, A/B/C = menos, I = inactivo. |
| **Lead time** | Cuántos meses tarda en llegar lo que pides al proveedor. |
| **Stock meses** | A cuántos meses de demanda equivale tu stock actual. |
| **Tránsito** | Lo que ya pediste o viene en camino (solicitados + embarcados). |
| **Mes comercial** | Mes de negocio que no empieza el día 1, sino en un corte (aquí: día 21). |
| **Colchón (buffer)** | Meses extra de cobertura por si la demanda se adelanta o el barco se atrasa. |
| **Compra plaza** | Proveedor local/rápido: fórmula más corta (~2 meses de stock). |
| **Seed** | Número que fija el generador de datos para que siempre salgan los mismos SKUs ficticios. |

## Escala

- **Demo de este repo:** 100 SKUs, 3 locales, 12 meses.
- **Contexto profesional:** la misma lógica se aplicó sobre un catálogo de **más de 70.000 SKUs**.
